## Troubleshooting Common Issues

Install issues? Re-sync the app if a task appears on one device but not another.  
Performance problems? Archive finished projects periodically to keep the sidebar light.  
License/activation? Check the plan if reminders are greyed out.  
Compatibility? Update after a system language change if date parsing misreads input.  
Update failures? Export tasks before reorganising projects in bulk.
